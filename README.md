# DestinyHelix-2

一款单人卡牌肉鸽。在一张会不断向中心收缩的地图上走位，用《杀戮尖塔》式的回合制战斗击败中央 Boss。

当前可玩角色是铁卫（Ironclad）：80 点生命、99 金币，初始牌组为 5 张打击、4 张防御、1 张痛击，并携带遗物燃烧之血（战斗结束后回复 6 点生命）。

## 玩法

地图是 11×11 的格子，Boss 固定在正中心。开局从 8 个固定空地中选一个作为起点，之后只能上下左右移动，不能斜向。

格子有普通敌人、精英、事件、商店、篝火和空地。打赢战斗或处理完事件后，该格会变成已探索，再次进入时按空地计算。

每进入一格都会累计步数：空地（含已探索）+1，其余格子 +3。步数达到 12、24、36、48、60 时，地图由外向内各收缩一层，最多五层。Boss 格永不进入收缩区。

走进收缩区会掉血，层数 `n` 就是伤害系数：

- 空地：立刻失去 `n` 点生命
- 事件、商店、篝火：立刻失去 `3n` 点生命
- 战斗格：进场不掉血，但玩家每回合开始时失去 `n` 点生命。这份伤害无视格挡，战斗中如果再次收缩，系数会当场更新

战斗中打出卡牌、获得格挡、结束回合，然后敌人按意图行动。玩家回合结束时格挡清零。不能逃跑。

路上可以：

- 在篝火选择回复 30% 最大生命，或升级一张牌
- 在商店用金币购买卡牌、遗物、药水，或付费删牌
- 在事件中做选择；效果按顺序结算，若中途死亡，后面的效果不再执行
- 在合适的时机喝药水。药水用完即消耗

击败中央 Boss 即胜利。任意时刻生命降到 0 则本局结束，回到主菜单。

## 特色

- **收缩地图。** 走得越久，外圈越危险。路线本身就是资源，空地便宜，战斗和事件更贵。
- **牌组构筑。** 卡牌分攻击、技能、能力，战斗沿用抽牌、费用、格挡和意图。
- **局内成长。** 遗物监听战斗开始、回合、受伤、用药等时机；药水按战斗内外区分能否使用。
- **内容在数据里。** 卡牌、敌人、事件、遗物、药水和角色写在 JSON 中，效果由同一套结算逻辑执行。

## 运行

需要 Qt 5.14.2（Widgets）和支持 C++17 的编译器。用 Qt Creator 打开 `CardRoguelike/CardRoguelike.pro`，先编译 `corelib`，再运行 `app`。测试目标是 `tests`。
